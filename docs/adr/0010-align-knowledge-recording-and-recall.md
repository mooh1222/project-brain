# 기록 목적에 따라 지식과 개선 행동을 구분한다

2026-11-04, #114·#115·#117의 기록·회상 검증과 통합 검수에 따라
[ADR 0006](0006-use-temporary-topic-knowledge-drafts.md)의 범위·발견 선행·라우팅 보류를
아래 범위에서 재검토한다. 초안을 미검증 대기함으로 축소하거나 개선 행동과 근거 부족을
같은 백로그에 보내는 상충 안내, 개선 제안 회상 경로의 누락을 해소하기 위해서다.

- 초안의 주제는 기능·도메인뿐 아니라 조사 주제를 포함한다. 유용한 주제·출처·재개 가치가
  있으면 단건도 허용하며 모든 작은 작업에 생성을 강제하지 않는다.
- 일반 지식 질문·개발 재개는 초안 발견과 search→show를 사용한다. 개선 제안만 묻는 회상은
  백로그 본문을 직접 읽으며 초안 발견·일반 검색을 필수 선행하지 않는 예외로 둔다.
- 0006의 “backlog·pending 자동 라우팅은 나중에” 중 목적별 안내는 이번에 결정한다.
  지식은 초안 또는 기존 ingest로, 구체적인 개선 행동은 개선 제안으로 구분한다.
  검증 대기 인사이트(기존 기록)는 보존·명시적 조회만 하고 기본 신규 기록에서 제외한다.
  유용한 주제의 미검증 관찰은 초안의 가설·미결과 출처·한계로 남긴다.

판단 정본은 설치되는 `draft/references/knowledge-workflow.md`이며 기존 스킬·명령을
사용한다. 새 코드 라우터·상태머신·색인 채널은 도입하지 않는다. 0006의 비색인 작업 기억,
기존 형식 보존·선택 읽기·SHA 갱신 경계는 유지한다. 현재 범위의 상세 계약은
[통합 spec](../specs/2026-11-04-brain-knowledge-workflow.md)을 따른다.
