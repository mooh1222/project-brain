# 주제별 지식 초안은 활성 작업 동안만 유지한다

여러 세션에 걸쳐 바뀌는 개발 지식을 성급하게 Brain 객체로 확정하지 않으면서도 다음 세션에서 잃지 않기 위해, 소비 프로젝트에 주제별 지식 초안을 Git 추적·비색인 작업물로 둔다. 기본 위치 제안은 `brain/drafts/<topic-id>.md`이며 정확한 topic ID와 파일 계약은 통합 spec에서 확정한다. 초안은 정식 Brain 객체·원문·일반 검색 답변 근거가 아니며, 관련 작업 시작이나 명시적인 이어가기 요청에서만 찾아 `진행 중 지식 초안`으로 구분해 읽는다.

첫 버전에는 세션 시작 훅을 두지 않는다. 현재 프로젝트와 작업 요청으로 활성 초안을 찾아 하나면 자동으로 읽고, 여러 개면 범위만 보여준 뒤 선택한다. 실제 사용에서 누락이 반복될 때에만 초안 본문이 아닌 존재 여부를 알리는 가벼운 훅을 검토한다.

초안의 각 항목은 정식 Brain 적재·개발 백로그·어휘 판정 명부·폐기 또는 재사용 가치가 있지만 아직 정식 객체화할 수 없는 대기 인사이트 가운데 하나로 정리한다. 대기 인사이트는 `pending/insights.md`에 필요한 내용과 원본 초안 backlink·라우팅 영수증을 함께 남겼을 때만 처리 완료로 본다. 처리되지 않은 항목이 하나라도 있으면 초안을 유지하고, 모두 정리되면 파일을 삭제해 Git 이력만 남긴다. 완료 초안을 별도 보관함에 쌓아 또 하나의 지식층으로 만들지 않는다.
