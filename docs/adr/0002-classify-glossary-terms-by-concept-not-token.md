# 문자열이 아니라 독립 개념을 어휘로 적재한다

`GlossaryTerm`은 프로젝트에 등장한 문자열 목록이 아니라 독립적으로 질문하고 설명할 가치가 있는 프로젝트 고유 개념에만 사용한다. 하나의 안정된 개념이어야 하고, 뜻과 범위를 코드 구성요소 하나에 기대지 않고 설명할 수 있어야 하며, 별도 어휘가 없으면 질문하거나 다른 이름과 연결하기 어려워야 한다. 코드 식별자·함수·필드·enum 값은 실제 공용 이름으로 쓰이는 예외가 아니면 코드 위치나 의미 매핑으로 남기고, 같은 개념은 소유 도메인의 어휘 하나를 재사용한다.

어휘가 아닌 코드 값에도 재사용할 의미가 있으면 값마다 별도 어휘나 매핑을 만들지 않고 질문하고 설명할 만한 상위 의미 단위의 `DomainMapping` 하나로 묶으며, 실제 enum과 분기 위치는 `CodeLocator`로 연결한다. 그 상위 의미 단위가 프로젝트에서 실제 이름으로 쓰이면 `카누 레이스 상태`처럼 `GlossaryTerm`으로 두고 매핑을 연결할 수 있으며, 재사용할 의미가 없는 변수명은 별도 Brain 객체를 만들지 않는다.

대표 어휘·동의어·별칭에는 사용자나 팀의 표현, 현행 기획·운영 문서, 화면 이름처럼 실제로 개념의 이름으로 쓰인 근거가 필요하다. 코드명은 코드 밖에서도 개념 이름으로 사용된 근거가 있을 때만 허용하며, 에이전트가 설명을 위해 만든 표현은 실제 사용 근거가 생기기 전까지 `GlossaryTerm`으로 만들지 않는다. `candidate`도 이 어휘 문턱을 통과해야 하며, `reviewed`는 근거의 사실 여부와 함께 어휘 분류·정의·범위·대표 이름·소유 도메인까지 검증된 상태를 뜻한다. 자연어 등가 표현은 동의어로, 옛 이름·화면 표기·내부 이름·실제로 이름처럼 쓰이는 코드명은 별칭으로 구분한다.

동의어와 별칭의 구분은 이름의 성격을 설명하기 위한 것이며 신뢰도나 검색 권한의 차이가 아니다. 대표 어휘·동의어·별칭 중 무엇으로 질문해도 같은 어휘와 연결 지식에 도달하고, 대표 어휘는 답변에 표시할 기준 이름일 뿐 검색 신뢰도 우선순위가 아니다. 같은 표현이 여러 개념에 걸리면 필드 종류로 조용히 하나를 고르지 않고 도메인·범위·근거로 해소하며, 그래도 뜻이 갈리면 모호성을 드러내고 사용자에게 확인한다. `GlossaryTerm.avoid`는 정식 검색 이름으로 취급하지 않고 대표 어휘로 고치는 교정 표현으로만 쓴다.

사람이 모든 어휘를 직접 검수하지는 않는다. 실제 사용과 정의·범위를 뒷받침하는 1차 근거가 있고, 추출자와 분리된 검증자가 어휘 자격·크기·대표 이름·다른 이름·중복·소유 도메인을 반박하며 확인했으며, 미해결 충돌 없이 최종 검사를 통과하면 `reviewed`로 적재할 수 있다. 에이전트가 끝내 풀지 못한 의미 충돌, 실제 팀 사용 여부, 대표 이름 선택, 개념의 병합·분리만 사용자 예외 판정으로 보낸다.

새 기준은 앞으로 생성되는 어휘에만 적용하지 않는다. 기존 코퍼스의 `GlossaryTerm`도 현재 `reviewed` 상태를 정답으로 간주하지 않고 같은 기준으로 읽기 전용 재감사한다. 결과는 실제 어휘 유지, 코드 세부사항으로 재분류, 기존 어휘의 동의어·별칭으로 병합, 문맥별 다른 뜻으로 분리, 사용자 판단이 필요한 모호성으로 나눈다. 감사 자체는 객체를 자동 삭제·수정하지 않으며, 독립 검증을 통과한 보고와 사용자 예외 판정이 끝난 뒤 별도 migration으로 반영한다.

첫 BB2 재감사는 실제 코퍼스 전체의 기계적 현황을 읽기 전용으로 측정하고, 개별 의미 판정과 변경 계획은 샐리의 카누 도메인부터 시작한다. 엔진의 합성 회귀는 구조적 안전망으로 계속 실행하지만 의미·검색·migration의 최종 판정을 임시 코퍼스나 fixture 성공으로 대신하지 않고 실제 BB2 데이터에서 확인한다. 첫 변경 전 기준점은 `docs/bb2-brain-object-model`의 `59422f05ea`이며, 승인된 변경을 한 묶음씩 적용한다. mutation 실패는 transaction rollback을 확인하고 사후 검증 실패는 즉시 멈춰 해당 묶음만 직전 기준점으로 복구한 뒤, Git 비추적 색인은 복구된 객체 코퍼스에서 다시 만든다.
