# 한국어 토크나이저는 kiwipiepy 단일 백엔드로 하고 어절 안 명사 결합형을 보존한다

색인과 질의가 공유하는 한국어 토크나이저는 pip으로 설치되고 버전이 고정된 kiwipiepy 하나만 쓴다. mecab-ko 우선 폴백 사다리를 없애고 정규식 분리는 테스트 주입 전용으로 남긴다. 형태소 조각에 더해, 같은 어절 안에서 연속한 명사 조각을 이어 붙인 결합형 토큰을 함께 보존한다(영문 심볼의 camelCase 조각과 원형 동시 보존과 같은 규칙). 색인 meta에 토크나이저 이름과 규칙 버전을 기록하고, 질의 시점의 값과 다르면 stale 색인과 같은 방식으로 거부한다.

mecab-ko 사전에는 프로젝트 복합명사가 없어 "인게임"이 "인"+"게임"으로, "럭키박스"가 "럭키"+"박스"로 쪼개져 개념 단위 토큰이 색인에 존재하지 않았다(객체 df 0). 2026-07의 어휘 명부 게이트는 이 토크나이저 공백을 위에서 우회한 것이었다. 사전에 없는 단어 옆에서 "이벤트"가 "이"+"벤트"로 갈라지는 문맥 의존 오분석도 있었고, kiwipiepy는 이를 바르게 분석한다. mecab은 brew 사전 경로에 묶여 있어 설치 유무에 따라 사람마다 다른 토큰이 나오며, 팀 공유 단계에서 색인과 질의의 비대칭 원인이 된다. 현행 코드는 색인과 질의의 토크나이저가 달라도 경고만 하고 검색을 계속하므로, 백엔드나 규칙이 바뀌면 옛 색인이 조용히 어긋난다. 결합형 보존은 BB2 객체 표면에서 "인게임" df 20, "럭키박스" df 27을 만들어 회수 층에서 문제를 직접 해결한다. 대가는 실모델 색인 rebuild 한 번과 골든셋 재기준이며, 사용자 사전·corpus 단어 추출은 이 결정에 포함하지 않는다.
