# Project Brain v0.3.3 — 프로젝트 고정 release 선택

적재 Python 진입점과 shell 래퍼가 PATH의 다른 엔진을 자동 선택하던 문제를 고친다.
소비 프로젝트의 실행 스크립트는 이 release 원본으로 갱신해야 한다. 런타임 bytes·실행 비트와
release 신원을 확인하는 검사는 유지한다.

## 포함 변경

- 명시 `PROJECT_BRAIN_PYTHON`을 유지한다. 미지정이면 실행 스크립트가 속한
  `.project-brain.json` checkout의 `.local/brain-tools/project-brain/bin/python`과 CLI를 쓴다.
  다른 cwd, 전역 launcher, 현재 Python의 import 가능 여부는 자동 선택 근거가 아니다.
- 고정 release Python·CLI가 없으면 프로젝트 prepare/설치 안내로 종료한다.
  자동 선택은 Python 환경변수를 정리하고 격리 Python으로 다시 실행하며 자식 CLI PATH도 맞춘다.
- shell 래퍼도 같은 resolver를 사용한다. BB2가 별도로 적용했던 PATH·환경 보정은 공통
  템플릿이 맡는다. BB2 전용 prepare 명령은 소비 프로젝트의 바깥 래퍼·팀 안내에 둔다.
- schema, 코퍼스, 검색·색인 계약과 의존성은 바꾸지 않는다. 색인 rebuild는 필요 없다.

## 게시와 검증

게시 전 후보 문서다. 엔진 필수 회귀와 독립 검수 후 커밋된 HEAD에서
`tools/release.py build --tag v0.3.3`을 실행한다. 로컬 smoke와 게시 URL의
`smoke --from-release` 결과, artifact 해시·source commit은 게시 완료 후 이 절에 기록한다.
