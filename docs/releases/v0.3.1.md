# Project Brain v0.3.1 — 게시 및 다운로드 검증 완료

Brain 지식 기록·회상과 임베딩 서비스 안내를 정리한 패치 릴리스다. 커밋
`84ee90e09ad3b5644254994a8483dfcb1615bfd6`에서 빌드하고 같은 커밋의 `v0.3.1` 태그와
[release](https://github.com/mooh1222/project-brain/releases/tag/v0.3.1)를 게시했다. 공개 URL에서
산출물을 다시 받아 `smoke --from-release`를 통과했다. BB2의 버전 고정·사본 병합과 실코퍼스
검증은 상위 #114의 후속 작업이다.

## 템플릿 변경 요약

- #115: `draft/references/knowledge-workflow.md`를 공통 기록·회상 판단의 정본으로 추가하고
  draft·query·ingest·session-ingest와 관련 reference를 연결했다. 개선 제안을 직접 회상하고,
  근거 부족 Insight를 초안의 미결로 다루며, 기존 검증 대기 기록을 보존한다.
- #116: 공유 임베딩 서비스의 첫 로드, 동시 요청, 예비 슬롯 대기 및 상태 확인·종료 안내를
  `ingest/references/ingest-tools.md`에 두고 query에서 참조한다.
- 통합 검수에서 용어와 ADR, 세션 추출의 미합의 후보 처리를 보완했다. v0.3.0 대비 템플릿
  12개 파일이 변경됐으며 새 엔진 kind·schema·CLI·검색 채널은 없다. 색인 rebuild도 필요 없다.

## 검증과 한계

- 릴리스 커밋의 Python 3.12.11 전체 pytest는 **2527 passed, 174 subtests passed**, 설치 ingest
  runtime unittest는 **151 tests, OK**였다. checkout을 편집 설치한 별도 임시 가상환경과
  `PROJECT_BRAIN_EMBEDDER=stub`을 사용했다.
- 로컬 및 공개 release smoke는 모두 `ok`였다. 검증한 wheel과 격리 설치 bytes, 적용 constraints,
  설치 파일 66개를 확인했고 두 번째 설치의 `created/updated/removed/adopted/skipped`는 모두
  비었다. 합성 소비자 batch·감사·조회·초안·세션 및 거부·재개·재실행 검증은 stub 임베더와
  정규식 토큰화로 수행했다.
- #117의 W-T1~W-T6 각 2회와 W-T7은 합성 프로젝트와 분리 판정으로 통과했다. 검수 수정 후
  W-T1·W-T3는 재실행했으며 W-T2·W-T4~W-T6은 이전 통합 기준점의 증거를 유지한다. 상세와
  한계는 [검증 보고서](../reports/2026-11-04-brain-knowledge-workflow-validation.md)에 있다.
- Python 3.13.6에서 기존 lint의 순환 심볼릭 링크 `raw/loop` 표적 테스트는 예상한
  `manifest_local_path_invalid` 대신 `manifest_local_file_missing`을 반환해 실패했다. #115의
  기준 커밋에서도 재현된 기존 차이다. 이번 3.13 전체 pytest는 중단해 통과로 집계하지 않았고,
  3.13 설치 runtime unittest는 151 tests, OK였다.
