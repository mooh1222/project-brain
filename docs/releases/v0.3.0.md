# Project Brain v0.3.0 — 게시 및 다운로드 검증 완료

bb2-work-tracker #93~#96의 색인·검색 비용 개선을 묶은 minor 버전이다. 커밋
`eb1a7e41407abc1c5aed38be04c4af398efe5c85`(버전 0.3.0)에서 정식 wheel을 빌드하고 격리 설치·공개
소비자 smoke를 통과했다. 같은 commit을 가리키는 `v0.3.0` tag와
[release](https://github.com/mooh1222/project-brain/releases/tag/v0.3.0)를 게시한 뒤, 공개 URL의
wheel·constraints·checksum을 다시 내려받아 `smoke --from-release`를 통과했다. 소비 프로젝트의
버전 고정·통합 검증은 그쪽 작업이다.

## 포함 변경

| 티켓 | 내용 | 상세 |
|---|---|---|
| #93 | `index rebuild --seed`로 같은 임베딩 신원의 벡터 재사용, 가중치 없는 신원 계산 | [2026-11-03 보고서](../reports/2026-11-03-index-seeds-93.md) |
| #94 | 동일 사용자·동일 신원 임베딩 서비스 공유, 전역 슬롯 예비 경로, `embedder status/stop` | [2026-11-03 보고서](../reports/2026-11-03-embedding-service-94.md) |
| #95 | 바뀌지 않은 표면의 토큰화를 건너뛰는 신선도 판정(기존 지문과 동치), eval 1회 판정 | [2026-11-04 보고서](../reports/2026-11-04-fast-freshness-95.md) |
| #96 | 장치 이름 캐시로 상주 검색 클라이언트의 torch import 생략, 틀린 캐시 1회 자동 회복 | [2026-11-04 보고서](../reports/2026-11-04-device-cache-96.md) |

색인 스키마는 v5 그대로이며 #95의 선택 캐시 테이블은 추가 전용이다. v0.2.0 색인은 rebuild 없이
쓸 수 있고, rebuild하면 빠른 신선도 경로가 켜진다. 임베딩 신원 문자열은 바뀌지 않았다.
