# Project Brain v0.3.2 — 게시 및 다운로드 검증 완료

[#121](https://github.com/mooh1222/project-brain/issues/121)의 v2 초안 완료 표시와 기본 목록 제외를
추가한 패치 릴리스다. 커밋 `b9e90fdaca738d5b12ebba228ec7adee66f9a5e4`에서 빌드하고 같은
커밋의 `v0.3.2` 태그와 [release](https://github.com/mooh1222/project-brain/releases/tag/v0.3.2)를
게시했다. 공개 URL에서 산출물을 다시 받아 `smoke --from-release`를 통과했다.

## 포함 변경

- v2 초안의 선택 `ingested.at`을 `draft update <topic> --expected-sha <sha> --state ingested|active`로
  기록하거나 해제한다. 상태 모드는 기존 본문·patch 입력과 배타적이다.
- 기본 `draft list`는 완료 v2를 제외하고 `--all`은 완료 표시와 함께 포함한다. 직접 show는
  가능하며 일반 patch 갱신은 같은 값을 쓰더라도 완료 표시를 지워 다시 노출한다.
- 완료 판정과 지식·작업 기록·개선 제안의 경계는 공통 workflow가 맡고, 실제 적재 결과를 받은
  draft가 최신 SHA로 표시한다. v1은 상태 기능 대상이 아니며 기존 파일은 삭제하지 않는다.
- 스킬 템플릿 5개를 갱신했다. 기존 실제 초안의 일괄 정리·상태 변경과 색인 rebuild는 없다.

## 검증과 한계

- Python 3.12.11·stub 환경의 표적 검사는 **72 passed**, 전체 pytest는
  **2540 passed, 174 subtests passed**, 설치 ingest runtime은 **151 tests, OK**였다.
- 기존 리더가 구현 diff 11파일을 직접 독립 검수해 PASS했다. 새 하위 에이전트는 사용하지 않았다.
- 로컬 및 공개 release smoke는 모두 `ok`였다. 검증한 wheel과 격리 설치 bytes·constraints·설치 파일 66개가
  일치하고 두 번째 설치의 `created/updated/removed/adopted/skipped`는 모두 비었다. 기존 합성
  소비자 검사는 stub 임베더·정규식 토크나이저로 수행했다.
- 기존 실제 초안 상태는 변경하지 않았다. 소비 프로젝트의 pin·스킬 사본 반영과 검증은 후속이다.

```bash
V=0.3.2
BASE=https://github.com/mooh1222/project-brain/releases/download/v$V
uv tool install "$BASE/project_brain-$V-py3-none-any.whl" \
  --constraints "$BASE/project-brain-$V-constraints.txt"
```
