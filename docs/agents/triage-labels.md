# Triage Labels

Matt engineering skills의 canonical 역할과 이 저장소의 GitHub 라벨은 같은 문자열을 사용한다.

## Category roles

| Canonical role | GitHub label | 의미 |
|---|---|---|
| `bug` | `bug` | 현재 동작이 깨진 문제 |
| `enhancement` | `enhancement` | 새 기능 또는 개선 |

## State roles

| Canonical role | GitHub label | 의미 |
|---|---|---|
| `needs-triage` | `needs-triage` | maintainer 평가 대기 |
| `needs-info` | `needs-info` | reporter 추가 정보 대기 |
| `ready-for-agent` | `ready-for-agent` | 충분히 명세되어 agent 실행 가능 |
| `ready-for-human` | `ready-for-human` | 사람의 구현·판단 필요 |
| `wontfix` | `wontfix` | 진행하지 않음 |

triage된 issue에는 category 역할 하나와 state 역할 하나만 둔다.
