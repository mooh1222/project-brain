# Domain Docs

이 저장소는 하나의 Project Brain 엔진 context를 사용하는 single-context 구조다.

## Before exploring

- 루트 [CONTEXT.md](../../CONTEXT.md)에서 공통 언어를 읽는다.
- 작업 영역과 관련된 [docs/adr/](../adr/) 결정을 읽는다.
- 파일이 없으면 조용히 진행하고, 실제 용어나 결정이 생길 때 `domain-modeling`으로 추가한다.

## Writing

- issue·spec·테스트·문서에는 `CONTEXT.md`가 정한 용어를 사용한다.
- 기존 ADR과 충돌하는 제안은 조용히 덮지 않고 충돌과 재검토 이유를 함께 밝힌다.
- CONTEXT와 ADR의 설계 상태를 현재 코드 구현 상태로 확대 해석하지 않는다.
