# project-brain Share Deck Design Notes

## Visual Thesis
Warm paper, ink-brown line diagrams, and a single terracotta signal color. The deck should feel like a calm architecture sketch for internal sharing, not a launch presentation.

## Content Plan
Open with the project-brain premise, then explain why it exists, how the engine/data split works, how the engine pipeline turns source objects into recall results, why object kinds exist, how objects connect and get stored, how recall uses surfaces and graph support, how operations keep trust state healthy, how installed skills guide agent usage, and close with the operating loop for team use.

## System Declaration
Use two backgrounds only: sand (`#F2EBDF`) for section-like slides and ivory (`#FBF7EF`) for dense explanation slides. Use one accent (`#C2693F`) only for active nodes, step badges, and final emphasis. Keep every slide cardless unless a node/cell is the diagram itself. Typography uses Work Sans with Pretendard fallback; Korean text uses `word-break: keep-all` and deliberate line breaks where needed.
